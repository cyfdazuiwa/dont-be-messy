# 静息 · Still(焦虑拉扯)

一个关于"把注意力拉回中心"的互动小实验:画布中央有一个呼吸的安全圈,你控制的小红点被四方涌来的波形不断拉扯 —— 按住它、抵抗这股力,在递进的三关风暴里坚持到底。

## 版本与文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | **p5.js · 莫兰迪线条版(主版本,根路径直达)** |
| `p5.html` | 旧地址,自动跳转到 `index.html` |
| `classic.html` | 初代 Canvas 2D 原生版(单文件零依赖,保留备查) |

## 玩法(p5.js 版)

- **按住画布拖拽**红点,抵抗四方正弦波形的拉力,让它留在呼吸的安全圈内。
- **关卡系统(三关递进)**:一 · 微风 → 二 · 涌浪 → 三 · 风暴。撑过每关时长自动过关,也可在过关卡点击"下一关"立即进入;第三关安全区持续收缩(带目标虚线预告)、双波连锁涌动、波形叠加二次谐波。
- **深呼吸技能**:**长按空格**,3 秒内波形拉力减半,伴随由中心向外扩散的圆形水波纹;松手或满 3 秒后进入 5 秒冷却。
- **手势控制(MediaPipe Hands,可选)**:点开始界面"启用手势控制"或按 `G` 授权摄像头后 —— **右手食指尖**实时映射到画布替代鼠标拖拽红点;**握拳**触发深呼吸保护(拉力减半 + 中心水波纹),**张开手掌**释放恢复常态;左下角以半透明显示摄像头镜像与手部骨骼连线。无摄像头/拒绝授权时自动回退鼠标,不受影响。
- **状态机与结算**:开始界面 → 游戏进行中 → 过关卡 → 通关/失败结算。结算显示坚持时间、得分、平静率与一句治愈文案;心率条满格触发"短暂崩溃",累计三次本场结束(失败结算,可"再试本关")。
- 触碰漂浮的正念粒子加分;贴住圆心进入**心流**,圈内减压与得分三倍。

## 运行

无构建依赖(p5.js 走 CDN):

```sh
ruby -run -e httpd . -p 8614
# 打开 http://127.0.0.1:8614/
```

快捷键:`空格` 长按深呼吸,`G` 开/关手势控制,`R` 随时重开整局;调试参数 `?debug` 下 `N` 跳过本关、`K` 压力拉满、`M` 合成握拳/手掌手势、控制台 `__mockHand(kind, nx, ny)` 可注入指定手部数据。支持鼠标与触屏。手势控制需在 `localhost`/HTTPS 环境授权摄像头(本服务即满足)。

## 技术要点

- 自由刚体 + 阻尼的轻量物理:四向弹簧拉力 × 实时振幅 × 关卡系数 × 呼吸倍率、有上限的指针橡皮筋、指数阻尼、边界反弹。
- 深呼吸倍率以指数缓动 1 → 0.5;水波纹为扩散圆环队列,呼吸期间周期性生成。
- 心率(压力值)驱动安全圈/波形/螺旋的配色与运动强度插值;背景恒定纯白。
- 灰色螺旋为阿基米德螺旋线,角速度与抖动幅度随偏移量和焦虑度增长;纸面颗粒一次性离屏绘制。
- `requestAnimationFrame` 渲染,`dt` 钳制防跳帧;适配 devicePixelRatio 与窗口缩放。
