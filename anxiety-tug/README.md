# 焦虑拉扯 · Anxiety Tug

一个关于"把注意力拉回中心"的互动小实验:画布中央有一个黑色安全圈,你控制的小红点被四方涌来的蓝色波形不断拉扯 —— 按住它,抵抗这股力,尽量让它留在安全圈内。

基于 HTML5 Canvas 2D + 原生 JavaScript,零依赖,单文件。

## 玩法

- **按住画布任意位置拖动**:红点会像被橡皮筋拴住一样跟向指针(有最大拉力限制,猛拉需要追赶)。
- **四周的蓝色波形**持续把红点往外拉:振幅实时变化,且会不定期"涌动"—— 某一侧突然增强并把红点狠狠拽向那边。
- **红色安全圈测试**:红点留在黑色圆内为**平静**(纸白底、蓝色波形);被拉出边界则进入**焦虑警示**——背景泛红、安全圈变红虚线、波形转红、环绕的灰色螺旋加速旋转并剧烈抖动。
- 拖拽和波形之间是一场持续的拔河:指针拉力有上限,涌动来临时要预判、借力、抢在 breakout 之前把点带回来。

## 计分

| 指标 | 含义 |
| --- | --- |
| 连续平静 | 红点在圈内连续停留的秒数(安全圈外的进度弧,30 秒满一圈) |
| 最佳纪录 | 历史最长连续平静(浏览器本地保存) |
| 平静率 | 开始游戏以来,红点在圈内时间占总时长的比例 |

## 运行

无任何构建与依赖,双击 `index.html` 即可;或:

```sh
ruby -run -e httpd . -p 8614
# 打开 http://127.0.0.1:8614/
```

快捷键:`R` 重新开始。支持鼠标与触屏。

## 技术要点

- 自由刚体 + 阻尼的轻量物理:四向弹簧拉力 × 实时振幅、有上限的指针橡皮筋、指数阻尼、边界反弹。
- 平静/焦虑两套配色在 0~1 的 `stress` 值间插值,出圈瞬间附带震屏与红圈闪烁。
- 灰色螺旋为阿基米德螺旋线,角速度与抖动幅度随偏移量和焦虑度增长。
- 全部渲染走 `requestAnimationFrame`,`dt` 钳制防跳帧;适配 devicePixelRatio 与窗口缩放。
